# KotoBlog (コトブログ) 🎙️✨

**話し言葉や音声メモから、読みやすいブログ記事を自動生成するWebアプリケーション**

「喋るだけ・思いついたことをつぶやくだけ」で、構成の整った魅力的なブログ記事が完成します。さらに、お気に入りの参考ブログの文章を貼り付けることで、その憧れの文体・トーンを真似て執筆させることも可能です。

---

## 🌟 主な機能

1. **🎙️ 音声入力 & つぶやき入力**
   - Web Speech API対応：マイクに向かって喋るだけでリアルタイムにテキスト化
   - 雑な箇条書きやメモをそのまま貼り付けるだけでもOK
2. **✍️ 憧れの文体を真似る（参考ブログ貼り付け機能）**
   - 真似したいブログの文章を貼ると、語尾のクセ・改行テンポ・感情表現をAIが解析して反映
3. **🎭 4つの基本スタイルプリセット**
   - **note・エッセイ風**（共感を呼ぶやさしい語り口）
   - **親しみやすいブログ風**（絵文字付きで明るいトーン）
   - **解説・ビジネス風**（説得力のある論理的な文章）
   - **要約・まとめ記事風**（見出しと箇条書きで整理）
4. **🤖 ハイブリッド生成エンジン**
   - Google Gemini API連携（Gemini 1.5 Flash / Pro 対応）
   - APIキーなしでも即座に動作する「スマート変換エンジン」内蔵
5. **📋 充実のエクスポート機能**
   - プレビュー表示 / Markdown / HTML / テキストのワンクリックコピー
   - 魅力的なタイトル複数候補（クリックでコピー可能）
   - おすすめハッシュタグ & SEOディスクリプション自動生成
   - 文字数カウント & 読了目安時間の表示
6. **🌓 ダークモード & 美しいデザイン**
   - 直感的で心地よいグラスモフィズムUI

---

## 🚀 使い方

1. [index.html](file:///Users/hidekazutsuyu/Desktop/demo-hallo/index.html) をブラウザで開きます。
2. **STEP 1**: 音声入力またはテキスト入力で思ったことを話す・入力する。
3. **STEP 2**: ブログスタイルを選び、必要に応じて「参考ブログの文章」を貼り付ける。
4. **「ブログ記事を自動生成する」** ボタンをクリック！
5. 生成された記事をMarkdownやHTMLでコピーして、ご自身のブログやnoteに貼り付けるだけです。
